## insilicoPCR 2.1.1

insilicoPCR 2.1.1 makes FASTQ read extension faster without changing what it finds. The full list is in [CHANGELOG.md](https://github.com/duceppemo/insilicoPCR/blob/master/CHANGELOG.md).

### Faster read extension

Read extension joins the primers of a product longer than a read. It extends the reads that carry them, in rounds that bait more of the sample's reads from the ends of the extended reads.

- **Baiting towards the product:** each round now baits only from the end of each extended read that its primer points to, the side the product lies on. The end behind the primer baited reads that no product holds.
- **Assays leave the rounds:** an assay takes no more rounds once its extended reads stop growing towards the product, or reach `-l` that way. It keeps that round's outcome. Before, the rounds went on while any end of any open assay grew, so one negative assay whose reads grew away from its product kept a whole sample's rounds going.
- **A smaller pool:** after round 1, Tadpole extends through the baited reads that round 1's extended reads reach (`_extensionLocalReads.fastq.gz`), instead of reading all the baited reads every round. Reads past those are still baited by the rounds, from the sample's reads.

The results were checked against 2.1.0 on four sets. All gave the same products and the same diagnostics.

| Set | Time, 2.1.0 → 2.1.1 |
|---|---|
| A *Globodera* species-panel sample | 1,490 → 1,195 s; rounds 11 → 9 |
| 50 designed products of 300 bp to 4.9 kb on a 65x *Brucella* read set | 278 → 222 s |
| Three more *Globodera* samples | about the same |
| 48 *Brucella* read sets | 5% faster |

### Upgrading from 2.1.0

- **Same products:** runs give the same products and the same `report_fastq_diagnostics.tsv` statuses as with 2.1.0.
- **`GenomeLocation`:** for a row marked `FASTQ read-extension call`, `GenomeLocation` is the product's place on its extended read. It can differ from 2.1.0's, because the reads now grow less behind the primers. The product's size does not change.
- **Files:** FASTQ samples' `detailed_report` folders hold one more file, `_extensionLocalReads.fastq.gz`.
