# Primer3 thermodynamic parameters

These 16 files are the thermodynamic parameter tables of Primer3 2.6.1 (`src/primer3_config/` of
https://github.com/primer3-org/primer3), copied unchanged. They are the same as the tables compiled into
Primer3's `ntthal` (`thal_parameters.c`). `ca.canada.inspection.thermo.ThalParameters` reads them.

Sources of the values (from Primer3's documentation): SantaLucia JR and Hicks D (2004) "The thermodynamics of
DNA structural motifs", Annu Rev Biophys Biomol Struct 33:415-40, and the papers it compiles.
