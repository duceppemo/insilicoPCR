## insilicoPCR 1.0.3

insilicoPCR 1.0.3 closes one of the gaps of FASTQ mode at `-m 3`, and insilicoPCR can now be installed with conda, from Bioconda. The full list is in [CHANGELOG.md](https://github.com/duceppemo/insilicoPCR/blob/master/CHANGELOG.md).

### FASTQ mode at `-m 3`: sites with 3 substitutions now bait their reads

The first bait matches primer k-mers within 2 edits at most, so at `-m 3` a primer site with 3 substitutions in each of its k-mers baited no read. When that happened, the product was missed although an assembly of the same reads gives it. At `-m 3` and more, a second BBDuk pass now keeps the reads within 3 substitutions of a 19-base stretch of an oligo of 19 bases or more, and adds them to the first bait's.

- With 3 substitutions, every site of a 20- to 25-base primer now baits its reads; 51% to 97% did before (300 random primers of each length).
- On SRR642185 at `-m 3`, the pass added 0.4% of the reads, the run took the same time and the reports were the same.
- Below `-m 3` nothing changes.

[Limitations](https://github.com/duceppemo/insilicoPCR/wiki/Limitations#known-gaps) gives the sites that can still bait no read: two deletions, 3 differences that include an indel, primers shorter than 19 bases, and 5' mismatches beyond the bases the k-mer leaves out.

### Install with conda

On Linux x64:

```bash
conda create -n insilicopcr -c conda-forge -c bioconda insilicopcr
conda activate insilicopcr
insilicoPCR --version
```

The package installs Java, BLAST+ and BBTools with insilicoPCR. Bioconda's bot updates it after each release, so it can be a release behind for a few days. See [Installation](https://github.com/duceppemo/insilicoPCR/wiki/Installation#with-conda-bioconda).

### Upgrading from 1.0.2

Nothing changes in the options, the files a run writes or the exit codes. Runs at `-m 3` or more can report products that 1.0.2 missed, and print one more line for each sample: the number of reads the substitution pass added.
