## insilicoPCR 1.0.1

insilicoPCR 1.0.1 moves to Java 25 LTS and adds a ZIP without a runtime, for package managers and containers: a Bioconda package is made from it. Results are those of 1.0.0. The full list is in [CHANGELOG.md](https://github.com/duceppemo/insilicoPCR/blob/master/CHANGELOG.md).

### Java 25 LTS

The portable ZIPs bundle Java 25 (LTS), and insilicoPCR is built for it, instead of Java 26, a short-term release whose updates ended when Java 27 came out. Java 25 gets security updates for years. Reports are the same as with 1.0.0.

### The ZIP without a runtime

`insilicoPCR-1.0.1-linux-x64-no-runtime.zip` (about 9 MB) holds insilicoPCR and its libraries, without Java, BLAST+ and BBTools. It is for an environment that has them already, such as a conda environment or a container:

- Java 25 or later, from `JAVA_HOME` or `PATH`;
- NCBI BLAST+ (`blastn`, `makeblastdb`) and BBTools (`bbduk.sh`) on `PATH`. Tested with BLAST+ 2.17.0 and BBTools 40.04, the versions the portable ZIPs bundle.

Without a `runtime` folder beside it, insilicoPCR runs the programs it finds on `PATH`; `QAlog.txt` names them and their versions. A portable ZIP always runs its own. Before each release, CI runs this ZIP on Java, BLAST+ and BBTools from conda-forge and Bioconda. See [Installation](https://github.com/duceppemo/insilicoPCR/wiki/Installation#without-the-bundled-programs-package-managers-containers).

Most users should keep downloading the portable ZIP for their system, `insilicoPCR-1.0.1-linux-x64.zip` or `insilicoPCR-1.0.1-windows-x64.zip`: nothing else needs to be installed.

### Upgrading from 1.0.0

Nothing changes in the files a run writes, the options or the exit codes. `QAlog.txt` and the HTML report give Java 25 as the Java runtime.
