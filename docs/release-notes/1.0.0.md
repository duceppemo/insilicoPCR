## insilicoPCR 1.0.0

insilicoPCR 1.0 fixes the formats and the command line that scripts and pipelines depend on. From 1.0 on, the columns of `report.tsv`, the files a run writes, the options and the exit codes change only with a new major version (2.0). It also fixes the last calling error the reviews found, in primers that overlap head to head. On 2,022 Brucella assemblies and on the FASTQ samples it was checked with, it reports the same products as 0.15.4. The full list is in [CHANGELOG.md](https://github.com/duceppemo/insilicoPCR/blob/master/CHANGELOG.md).

### The 1.0 formats

- **`report.tsv` has every column in every report**, in one order, empty where it does not apply. Before, the probe columns and `SizeCheck` were left out when no assay had a probe or a size, which moved the columns after them. The header is the format: `Sample, Assay, GenomeLocation, AmpliconSize, Contig, ContigDescription, ForwardPrimer, ReversePrimer, ForwardMismatches, ReverseMismatches, Forward3PrimeMismatches, Reverse3PrimeMismatches, Strand, Probe, ProbeLocation, ProbeSize, ProbeMismatches, Forward5PrimeUnpaired, Reverse5PrimeUnpaired, Pairing, Source, SizeCheck`. See [Reports](https://github.com/duceppemo/insilicoPCR/wiki/Reports) for the cell rules and the row order.
- **New columns:** `Pairing` (`designed`, `one-primer`, `two-assays`) and `Source` (`assembly`, `reads`, `extension`). Before, only the primer IDs and the description's wording told these.
- **`report_samples.tsv`** beside each report lists every sample, analysed or left out and why, with its products counted. This is where a script finds the negatives.
- **Standard output** holds insilicoPCR's own lines, including `Report written to <report.tsv>`. What BLAST+ and BBTools print goes to standard error.
- **Exit codes:** 0 when the run is done, 1 when the run started and failed, 2 when the command line cannot be used as given (nothing started).

### Fixed

- **Primers overlapping head to head:** a product is reported only when each primer's 3' end lies past every base of the other primer that does not pair with the template. Before, a mismatch BLAST kept in its alignment did not count.
- **FASTQ:** read sets left out for their file names (a comma, an equals sign) no longer fail the run, with the assemblies beside them.
- **Application:** **Stop**, then **Run** into the same folder before the first run had ended, released the folder's lock on Linux.
- **Windows:** a file of a deduplicated volume in a reused output folder is no longer refused as a link (a junction still is).
- The command line checks the primer sequences before it makes the output folder. A `--tadpole-k` longer than the reads is named in a warning.

### Upgrading from 0.15.4

Results are those of 0.15.4, except for a product of primers overlapping head to head whose primer end sat on a mismatch of the other primer: it is no longer reported.

Scripts that read the files:

- `report.tsv`: read the columns by name. Renamed:
  - `Gene` to `Assay`;
  - `Contig Description` to `ContigDescription`;
  - `ForwardPrimers` and `ReversePrimers` to `ForwardPrimer` and `ReversePrimer`;
  - `Forward5PrimeUnaligned` and `Reverse5PrimeUnaligned` to `Forward5PrimeUnpaired` and `Reverse5PrimeUnpaired`.

  The probe columns and `SizeCheck` are always present. Columns 1 to 13 keep their positions. The application still opens reports of earlier releases.
- `report_fastq_diagnostics.tsv`: `Gene` is `Assay`.
- Standard output no longer holds makeblastdb's lines. A command-line mistake prints a short message on standard error, not the help on standard output.

Options and files that are refused or behave otherwise:

- `--memory` is the name of `--bbtools-memory`, which still works (not both at once).
- Exit code 2, not 1, for an output folder that is a file. `-v -v` exits 2.
- `+` is refused in every assay ID (before, only in a `mix=` reaction).
- A `key=value` word in a primer header that insilicoPCR does not read (`Tm=60`, a mistyped `sise=420`) is named in a warning.

Application labels: **Max 5' unpaired bases**, **E-value**, **Memory for BBTools and BLAST**; the gel viewer colours **By assay**.
