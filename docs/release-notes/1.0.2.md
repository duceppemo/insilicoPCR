## insilicoPCR 1.0.2

insilicoPCR 1.0.2 updates the programs and libraries the portable ZIPs bundle: BBTools 40.05 and JavaFX 27.0.1. It also corrects the documented limit of FASTQ mode. Results are those of 1.0.1. The full list is in [CHANGELOG.md](https://github.com/duceppemo/insilicoPCR/blob/master/CHANGELOG.md).

### BBTools 40.05

BBDuk, BBMerge and Tadpole are unchanged in BBTools 40.05; its file reading and writing were reworked. Reports are the same as with 40.04 on the five-isolate genomes and reads, on SRR642185, and on a nematode sample whose 1.4 GB multi-member FASTQ files (as Illumina's bcl-convert writes them) BBDuk read whole, in the same time.

### JavaFX 27.0.1 and newer libraries

The window and the synthetic gel use JavaFX 27.0.1. Commons CLI (1.11.0) and the build tools are newer too. From now on, Dependabot proposes newer libraries each month, and a monthly CI run tests insilicoPCR on the newest Java, BLAST+ and BBTools a conda installation gets.

### The FASTQ-mode limit, stated exactly

[Limitations](https://github.com/duceppemo/insilicoPCR/wiki/Limitations#known-gaps) now says exactly which primer sites bait reads: a site always does when some k consecutive primer bases differ from it by at most `-m` edits, at most 2, of which one deletion. The pages said `-m 3` baited sites with 3 substitutions; it never did, as BBDuk uses its edit limit alone. Measured bait rates are given for sites beyond the rule. Nothing changes in what a run does: when such sites are expected, run the assay on an assembly of the reads as well.

### Upgrading from 1.0.1

Nothing changes in the files a run writes, the options or the exit codes. `QAlog.txt` and the HTML report give BBTools 40.05 as the BBTools version.
